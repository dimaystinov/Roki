# Реализация режима калибровки в открытой сессии FPV

1. Расширить локальный сервер MuJoCo в scripts/sim_calibration.py и scripts/sim_roki2.py. Остановить стратегию при переключении, подготовить физическую сцену, отделить измерение от сохранения. Проверить порядок вставания, сохранения калибровки поворота и доступа к ходьбе.
2. Добавить в Qt-панель тестов FPV выбор режима, кнопки сценариев, результаты и редактируемые поля записи. Проверить обработку ответов только для SIM-ROKI2.
3. Проверить исполнитель удара, выделить настройку выхода из удара, оценить устойчивость по позе корпуса после выдержки. Проверить параметры подхода и сохранение наклона ходьбы.
4. В отдельной сессии MuJoCo запустить матч из FPV, прервать его переключателем, выполнить последовательность калибровки. Сопоставить измерения с сохранённым профилем и отдельно запустить матч через API. Записать настоящее окно FPV в собственном разрешении с указателем, измерения в окне симулятора и русские пояснения; валидировать формат и читаемость записей.
