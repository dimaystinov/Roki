# Автономный FPV Roki

Цель: macOS .app без исходного проекта и Homebrew на машине пользователя; Windows-пакет с тем же интерфейсом и видеоприёмником.

1. Зафиксировать зависимости; добавить PyInstaller spec, стартовый runtime hook и адаптацию поиска KDDockWidgets в frozen-пакете.
2. Собрать macOS arm64 пакет с Python, Qt, KDDockWidgets, GI typelibs, GStreamer и H.264. Проверить все Mach-O зависимости, запуск в очищенном окружении, импорт GUI и локальный тест RTP → QImage.
3. Подготовить Windows native bootstrap и отдельный воспроизводимый сценарий сборки/CI. Проверять на Windows; не выдавать сценарий за готовый проверенный exe.
4. Установить проверенный macOS пакет с резервной копией прежнего .app; создать архив для передачи, описать архитектуры и отсутствие notarization.
5. Тесты существующего проекта и документация ограничений/результатов.

Никаких автоматических команд движения или подключения при запуске. Сохраняется прежнее размещение пользовательских настроек.
