# Двигательные тесты и калибровка

Roki FPV запрашивает test.list у выбранного робота и test.describe для каждой карточки. Имена тестов, доступные параметры, варианты, значения по умолчанию и ограничения приходят в ответах робота. Этот же протокол обслуживает MuJoCo.

Откройте «Тесты», нажмите «Запросить тесты и формы». Получите управление и включите ручной режим. Выберите параметры в карточке и нажмите «Запустить». Прогресс и итог отображаются в этой карточке.

Рекомендуемый порядок — вставание, Rotation test, Short run, Long run, остальные перемещения. Коэффициенты Rotation test робот вычисляет и сохраняет автоматически в ходе теста. Для ручного замера робот возвращает список manual_parameters в задании.

После завершения Short run измерьте путь одной и той же точки робота от старта до финиша. В карточке появится поле motion.run_10_mm. Введите миллиметры, например 330 для 33 см, и нажмите «Записать измерения». GUI отправляет test.measure с номером завершённого задания, затем перечитывает сохранённые значения. Для Long run используется motion.run_20_mm. Прыжки и боковые проходы запрашивают свои измерения.

В симуляции тест начинается с отметки центра. MuJoCo показывает старт, финиш и фактическое перемещение с округлением до миллиметра. Полные измерения также доступны в подробностях результата карточки. Оператор переносит результат в те же поля и сохраняет через test.measure. Запуск игры после завершения теста выполняется из вкладки «Игра».

Двигательные тесты работают без запуска камеры, детектора и видеопередачи. Подход к видимому мячу и подход с ударом относятся к стратегиям во вкладке «Игра». Открытие вкладки или подключение к роботу не запускает видео. Для просмотра обработки во вкладке «Цвета и детекция» отдельно нажмите запуск детектора и запрос стрима. Рядом отображаются размер, FPS, потери и состояние обработки.

Сравнение выполнено с aleksey-yagubov/roki-ng e1ec00d и aleksey-yagubov/roki-ng-operator-gui c510c3f. Восстановлен принцип карточек исходного оператора. Поля ручного измерения добавлены поверх существующего robot-side test.measure.
