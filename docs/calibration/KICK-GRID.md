# Рабочая зона удара в MuJoCo

[Карта всех попыток](kick-grid-5mm.png) · [Показания камеры и исход каждого удара, CSV](kick-grid-5mm.csv)

1368 попыток. Для сильного удара подъём ударной стопы 45 мм, для слабого штатные 32 мм. Наклоны корпуса при ходьбе, ударе и возврате: 0,065 / 0,090 / 0,012. Для каждой стопы и силы проверены 342 точки: вперёд от центра корпуса 75–160 мм, от оси в сторону выбранной ноги 7–97 мм, шаг обеих осей 5 мм. Эти расстояния измерены до центра мяча. В каждой точке выполнен один удар. Результат относится к этой модели и профилю. Между узлами измерений нет.

В таблице указана наибольшая по числу узлов прямоугольная область, где во всех проверенных точках камера видела мяч, ударная стопа коснулась его, мяч переместился вперёд и робот сохранил стойку. Достаточность дальности и точность удара оценивайте отдельно по CSV. Крайние значения по разным осям вне этой области не определяют безопасный прямоугольник.

## Устойчивый удар с нужной дальностью

Отдельно от простого касания проверили продвижение по направлению удара. За ориентир слабого взяли 350–650 мм вокруг сообщённых 500 мм, для сильного — не менее 2513 мм (три четверти длины игрового прямоугольника 3350 мм). Это критерии анализа записи.
