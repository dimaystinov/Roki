# FPV Roki — 28 ноября 2026

Обновление автономного пульта для macOS Apple Silicon и Windows x64, с отдельным updater интерфейса Operator NG Ягубова.

## Что включено

- Текущие локальные изменения пульта: выбор способов удара в игровом интерфейсе и управление игровыми режимами.
- Отдельные `Update-Operator-NG` / `Run-Operator-NG`; загрузка точного коммита upstream, проверка запуска перед активацией, отдельные настройки и откат.
- Текущие исходники симулятора и программы робота в репозитории. Автономный пакет содержит пульт, а не прошивку робота или физический симулятор.

[Инструкция updater](../Operator-NG-updater.md). Замена одного внешнего `.py` не обновляет встроенные модули автономного `.exe` / `.app`; установите новый пакет FPV Roki.

## Проверки

Снимок кода сборок: `249d06903801fe5f434414889b9aa4587931cad4`. Последующие правки документации не меняют бинарные файлы.

- macOS: набор GUI и симуляционных тестов — **200 passed**, **67 subtests passed**.
- Исправлены Windows-сохранение параметров и повторное открытие временной XML-модели MuJoCo; тест Qt-панели использует настройки интерпретатора самого приложения.
- Проверена HTTPS-загрузка с включённой проверкой TLS при недоступных каталогах сертификатов разработчика; корневые сертификаты включены в поставку.
- Проверяется запуск готового приложения с временными настройками, отдельно от уже открытого пульта.
- Updater проверен на upstream-коммите `c510c3f2a84efb70ebffcb13fdab25d7177617a8`: импорт внешнего Python, QML и платформенный docking.
- Windows собирается в GitHub Actions и проходит тесты исходников, готового EXE, видео и установки upstream. Точный результат и SHA архива указываются в опубликованном релизе.

Проверка GUI не подключает физического робота. Работа с реальным роботом в этом выпуске заново не проверялась.

Полный набор тестов Linux-программы `roki-ng`, запущенный на macOS отдельно от пульта, дал 681 passed, 284 failed, 158 skipped. Среди причин — отсутствующий на macOS `CLOCK_BOOTTIME` и расхождения сценариев автономной игры с ожиданиями тестов. Это не успешная аттестация программы робота; результаты не скрыты и не используются как подтверждение её надёжности. Изменять согласованные движения робота ради упаковки пульта не стали.
