# Отдельная версия Operator NG Ягубова

Updater загружает актуальную ветку по умолчанию репозитория [aleksey-yagubov/roki-ng-operator-gui](https://github.com/aleksey-yagubov/roki-ng-operator-gui). Это отдельный интерфейс: исходники, настройки и версии FPV Roki не заменяются.

## Запуск

Скачайте и полностью распакуйте [последний выпуск Roki](https://github.com/dimaystinov/Roki/releases/latest).

- **Windows x64:** откройте `Update-Operator-NG.cmd`. После установки через `Install-FPV-Roki.ps1` доступны отдельные ярлыки Operator NG в меню «Пуск».
- **macOS Apple Silicon:** откройте `Update-Operator-NG.command` рядом с `FPV Roki.app`. Если приложение перенесено в `/Applications`, команда найдёт его там.

Нажмите **«Установить / обновить версию Ягубова»**. После успешной проверки нажмите **«Запустить отдельную версию»**. Для повторного запуска предусмотрены `Run-Operator-NG.cmd` и `Run-Operator-NG.command`.

Кнопка **«Вернуть предыдущую версию»** переключает код на предыдущую успешно установленную версию. Перед обновлением или откатом закройте отдельный Operator NG. Настройки при откате кода сохраняются, их автоматическое преобразование не выполняется.

## Как устроено обновление

1. Updater узнаёт актуальный SHA коммита через GitHub API и скачивает архив именно этого коммита.
2. Проверяет пути архива, размер и синтаксис Python. Linux-библиотеки из `native/` не извлекаются.
3. Открывает тестовое окно из новых исходников с временным каталогом настроек. Проверяет загрузку Python, QML и нативных панелей. К роботу эта проверка не подключается.
4. Только после успешного завершения атомарно меняет активную версию. При ошибке сохраняет прежнюю.

Python, Qt, видео-библиотеки и нативный модуль стыковки панелей берутся из FPV Roki. Логика `operator_gui` и QML берутся из скачанного upstream; единственное переопределение — платформенный `native_docking`. Это перенос upstream на Windows/macOS с адаптером, а не побайтово оригинальная Linux-сборка. Подмешивание отсутствующих upstream-модулей из нашей версии запрещено.

Отдельно устанавливать Python, Git, Qt или компилятор пользователю не нужно. Если будущий upstream потребует новые зависимости или несовместимый Qt, проверка остановит обновление; потребуется новый выпуск FPV Roki с обновлённой средой. Проверка запуска не заменяет испытания всех функций с физическим роботом.

## Где хранятся файлы

- Windows: `%LOCALAPPDATA%\Roki-Yagubov-Operator`.
- macOS: `~/Library/Application Support/Roki-Yagubov-Operator`.

`versions/<SHA>` содержит исходники; `config` — независимые настройки; `current.json` — активный и предыдущий SHA. В каждом снимке `roki-updater-manifest.json` записаны репозиторий, ветка, коммит и SHA-256 скачанного архива.

Updater обновляет только интерфейс оператора. Программу на роботе и прошивки он не меняет. Совместимую с upstream программу робота устанавливают отдельно.

## Замена одного Python-файла

В исходной установке `Roki FPV.cmd` / `Roki FPV.command` запускают файлы из репозитория. В автономном `.exe` / `.app` Python-модули встроены в пакет: замена `roki_operator.py` рядом с приложением их не обновляет. Для FPV Roki установите новый готовый выпуск; отдельный Operator NG обновляется приведённым выше updater.
